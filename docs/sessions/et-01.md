## Concepts the professor stressed

### CORS — the security rationale, not just the definition

The scenario: frontend on `localhost:3000`, backend on `localhost:8000` — different ports, so different origins, so the browser blocks the fetch.

**His reasoning for *why* the policy exists** (worth remembering word-for-word): modern web apps rely on heavily nested third-party JavaScript libraries. If a library is compromised, it could execute unauthorized background requests to an external server and **exfiltrate sensitive client data**. The Same-Origin Policy is the guardrail that stops this — the destination server must explicitly allow the calling origin in its headers.

→ [Solved: T1-2026 AN Q13 + Q18](../pyqs/t1-2026-an.md#q13-fixing-the-cors-error)

### GitHub Pages — static only

It serves HTML, CSS, images, and client-side JS. **No server-side runtime, no database.** You cannot host a FastAPI backend or handle form submissions on it. The fix: static frontend on Pages, backend on a real runtime.

→ [Solved: T1-2026 FN Q3](../pyqs/t1-2026-fn.md#q3-fastapi-on-github-pages)

### JSON parsing — the single-quote crash

`json.loads("{'score': 10}")` throws `JSONDecodeError`. Standard JSON requires **double quotes** for keys and string values. He demonstrated this live in code.

→ [Solved: T1-2026 AN Q7](../pyqs/t1-2026-an.md#q7-requests-text-vs-json)

### Docker — environment parity + the missing install

- **Parity:** an Ubuntu container built anywhere runs identically on Windows, macOS, Linux — the OS is inside the image.
- **The crash:** a Python app that can't find the `requests` library inside a container is missing `RUN pip install -r requirements.txt` in its Dockerfile. Containers are isolated — you must install everything explicitly.

→ [Solved: T1-2026 FN Q5 + Q11](../pyqs/t1-2026-fn.md#q11-the-missing-pip-install)

### HTTPS — the Caesar cipher explanation

A student asked what "encrypts data" means. His answer: the **Caesar cipher** with shift n=2 — 'a' becomes 'c', 'h' becomes 'j'. Instead of sending plaintext over the network, the sender transmits the shifted ciphertext; the receiver unshifts it back. A historic toy algorithm, not used in real protocols, but the perfect mental model for what encryption does: makes intercepted traffic unreadable.

→ [Solved: T1-2026 FN Q6](../pyqs/t1-2026-fn.md#q6-why-https-for-tokens)

### asyncio.gather — the bottleneck arithmetic

5 requests in parallel: 4 finish in 1 second, 1 takes 10. **Total: 10 seconds.** Gather launches everything simultaneously but must wait for the slowest — the total execution time is the max, not the sum.

→ [Solved: T1-2026 AN Q21 + FN Q7](../pyqs/t1-2026-an.md#q21-asynciogather-with-a-hanger)

### Secret keys — the .env workflow

Never hardcode keys. Store them in `.env`, add `.env` to `.gitignore` **immediately** (the oversight he named: developers remember .env but forget .gitignore), load with `os.getenv()`. If keys reach a public repo, rogue actors scrape them, impersonate you, and it's "a security disaster."

→ [Solved: T1-2026 AN Q5 + FN Q8](../pyqs/t1-2026-an.md#q5-what-goes-into-gitignore)

### Coordinates — the swap that produces garbage

The Haversine distance function expects (latitude, longitude). A database storing (longitude, latitude) feeds swapped coordinates — the math then points to a completely different location on the globe. Distances come out "unrealistic" — off by thousands of kilometres — but **no error is raised**.

### Serverless memory limits

A script loading a 2GB file works on a laptop (8–32 GB RAM) but crashes on a free-tier Cloud Function (128–512 MB). The environments enforce strict limits; the fix is streaming, not bigger plans.

→ [Solved: T1-2026 FN Q10 (RAM) + AN Q17 (time twin)](../pyqs/t1-2026-fn.md#q10-serverless-memory-limits)

### Prompt injection filters — case variation defeats exact matching

Blocking the word "ignore" fails against "IGNORE". Robust filtering: **lowercase the input, then use regex patterns** rather than exact string matches.

→ [Solved: T1-2026 FN Q12 + Q23](../pyqs/t1-2026-fn.md#q12-bypassing-the-word-filter)

### Caching — the Twitter slow-network example

A student said "I can't understand caching." His explanation: load Twitter on a slow connection — the sidebar, templates, and static UI render instantly while the tweets lag. Those static assets are cached **locally in your browser**; the dynamic content isn't. **Cache-Control: public, max-age=3600** authorizes proxies and CDNs to serve copies — identical requests never reach the origin. To force fresh data: append a random query parameter (`?t=123`) — a new URL is a new cache key.

→ [Solved: T1-2026 AN Q19 + Q22](../pyqs/t1-2026-an.md#q19-what-max-age3600-does)

### LLM prompts — system vs user hierarchy

System prompts (developer prompts) declare core operational rules; user prompts carry the transient input. LLMs assign **significantly higher attention weights to system prompts** — which is why separating them prevents users from trivially tricking the model.

→ [Solved: T1-2026 AN Q23 + FN Q15](../pyqs/t1-2026-an.md#q23-defending-the-llm-from-the-input-field)

### Database race conditions

Two users sign up with the same username at the same millisecond. Without a lock, both availability checks pass simultaneously, both writes proceed — duplicate entries or an exception. The fix: explicit database locking (or a unique constraint).

→ [Solved: T1-2026 FN Q16](../pyqs/t1-2026-fn.md#q16-the-username-race-condition)

### ML data leakage — memorization vs generalization

200 test reviews accidentally in the training data: the model memorizes the correct labels for those specific examples. The inflated accuracy (94% → 76% after cleanup) reveals the true performance was hidden. "Once the leaked data is removed, the model can no longer rely on memory."

→ [Solved: T1-2026 AN Q16 + FN Q17](../pyqs/t1-2026-an.md#q16-the-fraud-model-collapse)

### API gateway + redundancy

80 microservices with hardcoded URLs in the client = chaos. An API gateway is the **single entry point** with centralized routing and authentication. A single gateway is a single point of failure — during traffic spikes it crashes and takes the platform down. The fix: **multiple gateway instances behind a load balancer**.

→ [Solved: T1-2026 FN Q26–28 (StreamFlix)](../pyqs/t1-2026-fn.md#q27-surviving-the-crash)
