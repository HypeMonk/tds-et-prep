    Study plans¶

    Pick your countdown · every plan uses the same priority order · frequency table drives everything

    How to pick

    Be honest about how many days you actually have — a 3-day plan you follow beats a 7-day plan you abandon on day 4. The full plan assumes 4–5 hours a day; the shorter plans 3–4. Every day lists its hour budget — if you have more time, add another PYQ paper or a second mock, not more reading.

    Topic coverage checklist — tick as you go

    The exam draws from the six official topics. Whatever plan you follow, make sure each box is ticked by exam day:

    • T1 Observability & Monitoring — read · practiced via Mock-1 M1–M4
    • T2 Data Pipeline Integrity — read · practiced via Mock-1 M5–M8
    • T3 CI/CD & Release Security — read · practiced via Mock-1 M9–M12
    • T4 Reliable AI/LLM Systems — read · practiced via Mock-1 M13–M16
    • T5 Web/API/Infra Fundamentals — read · practiced via Mock-1 M17–M22
    • T6 Applied AI Judgment — the grading guide + one full mock Section 2

    This term's paper: 41 of 80 marks are written

    Every plan below now includes writing practice — short answers and a timed full mock — because Section 2 (Applied AI Judgment) carries 41 of 80 marks (official structure). Don't skip those steps: the writing method is the fastest block of marks to secure, and it only becomes yours by doing it.
